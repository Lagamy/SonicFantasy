## Core

Follow camera and setCameraPosition move the entity.
- **BasicMesh** (2026-10-08, not run): format = data. `VertexLayout` (VertexLayout.h/.cpp): members {name, type Float/Vec2/Vec3/Vec4/U8Vec4, attrib location, offset}, packed, `stride`; `addMember` (throws dup name/location), `memberIdFromName`, `setupVertexArray(vao)` (U8Vec4 = integer attrib, binding 0). `VertexLayout::standard()` = struct `Vertex` (0 pos, 1 normal, 2 uv, 3 color, 4 u8vec4 bones, 5 weights; offsets checked once, throws on mismatch), used by all SADX/Shadow importers. `BasicMesh::verticies` is a `VertexArray` (bytes + `pLayout`, `setLayout` only while empty): standard layout = vector<Vertex> API (`push_back`, `[]`, range-for, `size`, `resize`, `=` vector/braced list; importers unchanged); other layouts throw there, use `setMember<T>/getMember<T>(memberId, vertex)` (type-checked). Optional u32 index, triangles, manual destroy. Custom layouts are owned by `Graphics::vertexLayouts` (below). **Shader**(name) loads `Assets/Shaders/<n>/{vertex,fragment}.glsl`, throws with log; `HasTextureLocation`. **Texture**: RGBA8 pixels, `create()` → SRGB8_ALPHA8, `filter`/`wrap` (nearest/clamp default), `mipmaps` (bleed transparent texels' color, full chain).

## Culling
Bounding sphere per model from rest pose (+margin); `Entity::bounds` = model ∪ collision (`refreshBounds` in every setter that changes model/collision/physics; manual `collisionId` → call it). `SpatialIndex`: static entities (instance, no physics, existing at `rebuild()`) in a BVH; dynamic (physics, `behaviorNotCulled`, created later) in a flat list. Renderer queries frustum ∩ farPlane; `Entity::draw` retests. `nearestDistance(point, max)`: distance to the closest entity sphere, static BVH + dynamic list (no longer used by the editor camera, 2026-10-09). Not built: contact broadphase from index (per-tick grid instead), draw sorting (docs/RENDER_DRAW_LIST_DESIGN.md).
- **Script files in AssetPanel** (2026-10-10, not run): script folders have toolbar New Lua file / New folder, `scriptEditor` setting (`scriptEditorCommand`, empty = xdg-open), tile menu Open in editor / Delete (confirm). Writes both `Assets/Scripts/<game>`|`Assets/External/Scripts` and source tree (`SF_SOURCE_DIR`), then `reloadScripts`; empty folders via `scriptDirs`; Open uses the source copy; game reads scripts only at start.
- **Script copy/paste/folder delete** (2026-10-10, not run): tile menu Copy / Ctrl+C, toolbar Paste / Ctrl+V (`copiedSource`, `pasteScript`, `_copy` suffix when taken, both trees); right click on a Global External folder tile = delete dialog (`deleteScriptFolder`, `drawFolders` out param `pRightClicked_`); script tiles = "LUA" on light green (no folder icon).
