# Architecture: core types, levels, culling (compact)
Part of the ARCHITECTURE twin set (index: `docs/ai/ARCHITECTURE.md`). Human source: `docs/ARCHITECTURE.md` (= ARCH; grep it for detail). Tags: E external, O observed (user), H hypothesis.

## Core
- **Globals**: inline vars in `Globals::App` (window, timing), `Game` (cameras, entities, levels, behaviors, gameplaySystem, spatialIndex, gameEvents, cameraTarget…), `Discs`, `Mouse` (cursorFree). GPU pools in GPU_Globals.h.
- **Pool/PoolMap**: deque slots, `PoolId{id, generation}`, free reuse, alive flags; `add` never moves elements (refs valid until slot removed). PoolMap adds `nameToId` (duplicate keeps first). `remove` calls `destroy`. Across removals keep PoolId and re-lookup.
- **Camera**: yaw/pitch (±89), 45°, near 1, `farPlane` 50000 (UI slider ≤500000) = the one render/sim distance; speed 50, ×3 Shift; focus regain resets mouse baseline; `frustumPlanes`, `sphereInFrustum`; UBO std140 {view, projection}.
- **BasicMesh**: interleaved Vertex (0 pos, 1 normal, 2 uv, 3 color, 4 u8vec4 bones, 5 weights), optional u32 index, triangles, manual destroy. **Shader**(name) loads `Assets/Shaders/<n>/{vertex,fragment}.glsl`, throws with log; `HasTextureLocation`. **Texture**: RGBA8 pixels, `create()` → SRGB8_ALPHA8, `filter`/`wrap` (nearest/clamp default), `mipmaps` (bleed transparent texels' color, full chain).
- **Entity**: `sourceEngine` (SA_NINJA / STH2005_ONE) picks instance pool; no instance until `setSAGPUInstance`/`setONEGPUInstance` (once; 2nd throws). Transform = translate(position)·rotation, cached, dirty via setters. `moveTo`/`turnTo` (sim, keep previous) vs `setPosition`/`setRotation` (teleport). `renderPosition/renderRotation` by interpolation alpha. ONE-only: `changeActiveMesh`, `changeActiveTexture`, `switchMeshPart(previous, desired)` (builds `<mesh>|<prev>><desired>` once). `playSAMotion`, `playONEMotion(key, loop)`. `markForDestroy`; `selfId`; `destroy` removes instance, behaviour set, script state.
- **SAMesh**: nodes (parent before child, rest transform, BAMS rot, flags), submeshes own BasicMesh + `textureIndex`; named `<rel>@0x<off>`; `users`; relocated rel cached in `relModules` until last mesh freed. `composeNinjaTransform` (order H). **SAInstance**: mesh, shader, set, binding, `nodePose`.
- **ONE (STH2005::ONE)**: PoolMap by disc path; bytes + entries + decoded `meshes` (from ModelKey recipe, `meshByName`, `meshParts`), `textureDictionaries`, `bindings` (missing texture name → printed, untextured), `motions`. `users`; archive is part of identity (TXD names repeat). Instance uses one archive; foreign TextureKey decoded into it as `<archive>|<entry>` (FRUIT). **ONEInstance**: archive, shader, mesh/TXD/binding indices, `framePose`, `motions` (one per skeleton), extra +90° Y (`RenderWareYawDegrees`, H from Shadow, applied to all RW). Skinned atomic: world[skin bone]·invBind → `boneBuffer` (≤256). Motion 60 fps H, cubic Hermite H, Euler `Rz*Ry*Rx` H (`ONEEulerYZX` alt); `attachedPart` motions skip first bone.
- **TextureSet** (SADX): `.gvm` textures in file order (`ordered`), named by path, `users`, `saBindings`. **TextureBinding**: SAMesh submeshes resolved against a set once; index past end throws. Failed instance creation rolls back.
- **SAMotion**: PoolMap `<rel>@0x<off>`, keys per node; 30 fps H, linear, short-way BAMS, holds last key.
- Split rule: shared skeleton/rest in resource, animated pose in instance.

## Levels
- **Level** (PoolMap): `sourceEngine`, `instanceId`, position; `setSAGPUInstance(shader, SALandTableKey, SATextureSetKey)` / `setONEGPUInstance(shader, LevelKey)`; destroy removes instance, collision, entities.
- `setSAEntities`: Entity per SET record whose type the table lists (model, textures, `setSACollisionShapes`, first motion looped); rotation Rz·Rx·Ry by default (E: 93 functions) or the object's own recipe (`SAEntityKey::rotation`, from rotate calls 0x8004AFDC z/0x8004B3E0 x/0x8004AF5C y; 7 objects); no scale (SET scale = parameters, E); `stageEntities` added after records; marker for others.
- `setONEEntities`: Entity per placement record the table lists; position + yaw + level offset (H); `EntityKey::layout` Single / RingLine / Variant (first param = `.BIN` info index, H); first motion looped for enemies/characters, else once-hold; rotation degrees Y,X,Z conjugated by yaw (H; ring Y only). Unlisted types → colored marker crosses (`collisionView.markers`, "Markers" window). Stg0100 places cmn+nrm+hrd+ds1 (mission alternatives H, unhandled).
- Streaming (`LevelStreaming.h`, both): piece sphere within farPlane → upload, draw if in frustum; beyond farPlane×1.5 (H) → free GPU; CPU kept. Pieces = game chunks.
- **SALevelInstance**: SALevelPiece (SAInstance + COL sphere) per COL with flag 0x80000000 (H: rest collision only); texlist names → set names (missing throws); `skippedTextures` (`m8_shadows`).
- **ONELevelInstance**: pieces (sector box sphere + submeshes) of every `.RG1` in section archives, skipping `skippedEntries` (`_D_`, `_G_` sky domes H); textures from `stgNNNN_texCM.one` TXD (case-sensitive, missing throws); STH2005 shader unskinned.

## Culling
Bounding sphere per model from rest pose (+margin); `Entity::bounds` = model ∪ collision (`refreshBounds` in every setter that changes model/collision/physics; manual `collisionId` → call it). `SpatialIndex`: static entities (instance, no physics, existing at `rebuild()`) in a BVH; dynamic (physics, `behaviorNotCulled`, created later) in a flat list. Renderer queries frustum ∩ farPlane; `Entity::draw` retests. Not built: contact broadphase from index (per-tick grid instead), draw sorting (docs/RENDER_DRAW_LIST_DESIGN.md).
