## Loop
1. User records: `.venv/bin/python tools/shadowLiveLog.py --pad 8056ED4C tools/<n>.csv`. NEVER run it (overwrites CSV). Always logs camera `cam_eye_x/y/z`, `cam_target_x/y/z` raw (2026-10-06; empty if unreachable).
2. `python3 tools/makeReplay.py tools/<n>.csv Scripts/shadow/replays/<n>.lua` → rows {t, fwd=−pad_fy, right=pad_fx, A=bit0, phi, pitch (camera d.y per unit horizontal; 6th field only with camera columns; 2026-10-07)}; start; heading0 = first velocity dir with pl>10 (H). `makeReplay.py tools/<n>.csv --check-camera [--ai]`: camera phi vs stick-vector phi (writes nothing).
3. Register: `sf.include("shadow/replays/<n>.lua")` in `Scripts/shadow/main.lua` + name in `ORDER` (`Scripts/shadow/replay.lua`).
4. User builds/runs, stdout → `tools/port_run.txt`; R cycles ORDER. REPLAY line: name, tick, t, x y z (pre-move), vx vy vz (post), motion, heading, faceHeading, turnSpeed, turnRate, grounded, gn xyz, touchingWall, wn xyz, speed word, growth cosine, growth target (last three: 2026-10-07, 0 when no growth ran; compareReplay ignores them), then step-in speed (after contact projection), step-out speed (before press), step normal xyz (2026-10-07; stale on non-ground ticks), then velocity at tick start vx vy vz (as the engine step left it; fields 31-33).
5. `python3 tools/compareReplay.py tools/<n>.csv tools/port_run.txt <n> [step]` → per 0.1 s pl / vy / height orig/port/diff, behavior/motion, path drift (from each start, orig turned to port axes), facing, stick reversals (≥170°, "same side"/"SIDES DIFFER" over 0.05 s). compareReplay takes the LAST round in port_run.txt.
   `--ai` = compact: summary line (max diffs, first over pl>5 h>2 drift>10 face>5, reversals) + rows `t pl dpl vy dvy h dh drift face beh`, quiet runs → `t0-t1 ok`. USE THIS, not the tables.
   Per-frame view: `python3 tools/digestRun.py tools/<n>.csv [--from T --to T --every N]` / `... tools/port_run.txt <n> [...]`; port axes, pos from start, decoded cols (W/rate/ang = w11-13), dupes dropped; port digest ends `wall wx wy wz`; orig `--contacts` (flags + changed hit/ground words; `--words` hex list limits them), `--absolute` (level pos = (−z, y, x)). Never read raw CSV / port_run lines.
6. Decode → port with evidence comment → REF + twin. I never build/run.

## Known limits
- frame_times: wall clock + catch-up chains (≥3 rows <8 ms apart with changing (pl,vy)) add frames; ignore first 0.05 s. Counting from value changes overcounted 5–8% (dropped). 60 Hz H.
- Replay row applies from half a tick before its stamp (ROW_TOLERANCE_TICKS 0.5, H): stamp phase drifts through a recording, so ±1 tick at some events is expected.
- compare pairs each orig row with nearest port tick, samples at count×step.
- Port rest vy −11.34 (press), orig 0. Port ground 5.02 below recorded height → START_LIFT −5.0; compare anchors height at SETTLE_TIME 0.25 s.
- Missed jump-start frame (11/16: first pressed row shows vy 97.52) → A one frame late (vy +2). Port height column one tick behind its velocity.
- Exact stick reversal (SIDES DIFFER) ends usable comparison. Recording advice: sweep stick round or release a few frames, never flip through centre.
- 1–2 frame alignment error normal. Rules fitted to a recording need a DIFFERENT recording to validate.
