# Engine usage (compact; human doc docs/ENGINE_USAGE.md wins)
Not run.
- Lua: `sf.loadLevel(name)` → handle; `sf.unloadLevel(h)` queued to next tick; `sf.levelExists(h)`. One level at a time (overlap).
- `Loading::loadLevel(name)` (src/Loading/LevelLoader.{h,cpp}): reads `Assets/Levels/<name>/<name>.json` (repo `Levels/`, `CopyLevels` copies at build), builds keys once per name (cached in `Recipe`: strings in deque, keys in unique_ptr; instances keep pointers), `addLevel`, then engine steps: sadx = `setSAGPUInstance`/`setSACollision`/`setSAEntities`; sth2005 = `setONEGPUInstance`/`setONECollision`/`setONEEntities`; `spatialIndex.rebuild()`. Failure → throws `Level 'X': msg` (Lua error), partial level removed.
- JSON common: `engine` ("sadx"|"sth2005"|"gltf"), `shader` ("SA"|"STH2005"|"GLTF"), `position` [x,y,z] opt, `textures`, `placementFiles` opt, `entityTable` opt, `typeNames` opt.
- sadx: `landTable {rel, offset (num or "0x..")}`, `textures` = .gvm string, `skippedTextures`, `stageEntities`.
- sth2005: `sections` [.one], `textures {archive, txd}`, `skippedEntries`.
- gltf (not run): only `collisions` [names of Collision/<name>.collision.json] opt; `model`/placement/tables ignored. Level read from `Assets/Levels/<Name>/` (also mirrored to source `External/`): `Models/<Name>_<cx>_<cz>_<k>.chunk.model.json/.bin` (standard ModelFile, submesh per texture, grid cell 256 m by centroid, cell >65536 tris split at median of longer side; `Loading/GLTFImport`, EDITOR) + `<Name>_tex<i>.png`; `Collision/*.collision.json/.bin` (`External/CollisionFile`: header version, name, vertexCount, triangleCount, hasTriangleValues, pieces; bin f32 xyz verts, u32 indices, opt u32 per-triangle attrs). glTF only read at import (New level, File>Swap level model, File>Swap collision>Add collision file); loading reads files only (works without EDITOR). Collision not chunked (quad tree is per triangle). Visual `GLTFLevelInstance` (chunk submeshes streamed like ONE pieces), shader `GLTF` (unlit, linear colour), all collision Solid two sided. File menu (gltf levels): Swap level model (path), Swap collision > Add collision file (path) + existing files (ticked = in use; pick = asks a path, overwrites that collision file with the new glTF, live rebuild if in use). `Level::setGLTFGPUInstance/setGLTFCollision/swap*/append*`, `GLTF_FILE`.
- Registry (top of LevelLoader.cpp; name → compiled table): SAEntityTable_EmeraldCoast, EmeraldCoastStageEntities, SAObjectTypeNames_EmeraldCoast, ObjectTypeNames, EntityTable_stg0100. New generated table = one line.
- Changed files (2026-10-08, not run): `Assets/External/Prefabs/<game>/<KEY>/Changed/prefab.json` (src mirror `External/Prefabs/...`, CopyExternal) = one `prefabs` entry (added/removed/shapesAdded/shapesRemoved/mesh/texture) for a key-built prefab in every level; read at startup (`Loading::loadChangedPrefabs`, after scripts+registerPrefabs). Order: game data < Changed < level `edits.prefabs` < entity; level removed cancels Changed added; level mesh/texture wins (Default = unset). `saveLevelEdits` writes only the level entry; per-entity diffs vs game+both. Global-scope edit (`PrefabScope::Global`) saves the file at once (EDITOR), empty = file removed; External prefabs have none.
- `edits` (opt, editor File>Save): `moved` [{index (own entity, creation order), position (world), source}], `added` [{prefab "SADX/SPRING", position, behaviors? (whole list, names)}], `prefabs` {prefab: {added:[names], removed:[names]}} (applied first), `behaviors` [{index, added, removed}] (own entity, diff from source + prefab edits), `shapes` [{index, shapes}] (whole bound area of an own entity when it differs; shape = CollisionShape fields, behavior by name|null), `prefabs` also has shapesAdded/shapesRemoved (removal = first equal shape), `added[].shapes`; models: choice = {kind default|disc|external, name} (disc = SADX `<rel>@0x<HEX offset>` / Shadow .DFF of the entity's archive; external = model name), `prefabs[].mesh`, `meshes` [{index, mesh}], `added[].mesh` (applied before textures); textures: choice = {kind default|disc|external, name} (disc = SADX .gvm path / Shadow .TXD entry of the entity's archive; external = png/jpeg name), `prefabs[].texture`, `textures` [{index, texture}] (diff from the prefab's), `added[].texture`; `externals` [{index, values {behaviour: {field: value}}}] + `added[].externals` (number/bool/string as is, vec3 [x,y,z], prefab name|null, entity = index in the level (own: index; added: sourceEntityCount + place in added)|null, resolved after all exist; undeclared or misfit → stderr, kept raw (Entity::externalsKept) and written back on save; 2026-10-08 not run); applied after entities are made; load clears prefab edits first; bad entry → stderr, skipped; rotation and meshes not saved. Save writes Assets/Levels and source Levels/ (`SF_SOURCE_DIR`).
- `source` (opt, editor File>Save Source Game Level, 2026-10-08, not run): same fields as `edits` minus `prefabs`, incl. `added`. loadLevel: make game entities → apply `source` (its `added` first; indices follow own entities) → `markSourceEntities` → apply `edits`. Restore/Return-to-source/edit diffs are from it; its `added` are own entities. A failed `source` `added` entry leaves a gone entity (index kept). Re-save = `composeSource` (entry per index replaced, `behaviors` composed, `added` appended), `edits` emptied. Prefab-wide source edits: `Assets/Levels/<level>/SourceGamePrefabs/<prefab name>/prefab.json` (+ src `Levels/`), read by `Loading::loadSourcePrefabs` into `Prefab::source`; layers: game data, changed, source, level; written as `mergePrefabEdits(source, level)`.
- `cameras` (opt, top level, File>Save and Save Source, 2026-10-08, not run): [{name, position, front, yaw, pitch, fov, near, far, enabled, main?, renderTarget? {width,height}}] = editor-added camera entities (`Editor::addLevelCamera`, in Level::entityIds after source ones). Made after `edits` by `addLevelCameras`; `main` sets mainCamera; renderTarget = new target of that size. Restore Source removes them (unsaved). Kept over Play/Stop in `Editor::keptCameras`.
- Levels: EmeraldCoast (sadx), Stg0100, Stg0000 (sth2005, no entity table).
- Add level: editor File>New level (`Loading::createLevelFile` makes the folder and writes Assets/Levels/<n>/<n>.json + Levels/<n>/<n>.json, refuses existing name, `Editor::newLevel` loads it; not run) or hand-written JSON + (table line) + game.lua starts + rebuild. Add game: `fill<Engine>` + branches in `readRecipe`/`loadLevel` + Level methods.
- Limits: tables compiled; all 4 Shadow placement files placed; JSON read once per run.
