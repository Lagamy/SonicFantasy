## State (2026-10-03 snapshot + later)
Importer stage + gameplay start: window, free-fly/follow camera, OpenGL renderer, Sonic (SADX GC) and Shadow (STH2005 GC) models/textures/motions straight from discs, levels (SADX Emerald Coast land table; Shadow stg0000/stg0100 RW worlds) with culling, collision, Lua gameplay. No lighting.

## Build
CMake ≥3.28, C++23, Ninja Debug in `build/`, one target `SonicSunset`, Linux only (vendored static GLFW, GL, dl, pthread, m). New .cpp → `add_executable` by hand. Include dirs = `src` + every header folder (bare includes `"Camera.h"`); new folder → `target_include_directories`. Runs with cwd `build/`; `CopyShaders`/`CopyScripts`/`CopyLevels` copy `Shaders/`, `Scripts/`, `Levels/` → `build/Assets/…`. nlohmann/json vendored (`third-party/nlohmann`, include `<nlohmann/json.hpp>`). Discs: `build/Disks/Shadow2005.iso`, `SADX.iso` (`Constants.h`). Lua 5.4.7 vendored (`third-party/lua`, static lib `lua`, compiled as C++ so errors = exceptions, `LUA_USE_POSIX`). `ENGINE_DEBUG` (Debug) gates Pool/PoolMap checks. CMake `EDITOR` (set by one `set(... FORCE)` line in CMakeLists.txt, edit it to switch; -D ignored) defines `EDITOR` + adds DebugUI/CollisionView/Text/ImGui sources; all uses are `#ifdef EDITOR` (GPU_Globals.h, Renderer, main.cpp input+debugUI, Level.cpp markers, DebugSetup markers fn, Utils.h GL debug); debugMode (= editor mode) starts true in the EDITOR build (Play/Stop toggle); OFF → never true. `.gitignore`: build/, dot folders, sadreamcasttools/.

## Runtime flow
createWindow (GLFW, GL 4.5 core debug) → `renderer.init` (GLAD, sRGB, depth, CCW backface cull, Default shader) → `addCamera("MainCamera")` = main camera → `Scripting::init`, `Scripts/main.lua`, `registerPrefabs` → shaders, open discs (`Globals::Discs`, stay open), level (`sf.loadLevel` → `Loading::loadLevel`), characters (Entity + `setSAGPUInstance`/`setONEGPUInstance` from keys, idle motions; nothing imported earlier: instances find-or-load and hold a user) → loop: deltaTime, poll, `processInputs`, `gameplaySystem.update`, `Entity::update` (motions, animation intent), `gameEvents.drain()`, `renderer.runAll(editor camera if active)` (camera UBO binding 0, levels then entities), `editor.draw`, swap → destroy.

## Conventions
`struct`, public members, `this->`; params end `_`, references prefixed `r` (`rCamera_`); PascalCase types/namespaces, camelCase functions/vars; origin by namespace not prefix; `#pragma once`; small utils header-only inline; explicit `init/create/destroy` (no RAII); GL 4.5 DSA (except `Texture::create` bind-to-edit); errors `throw std::runtime_error(std::format(...))`; one `/* */` block per non-obvious logical block with evidence label; tabs/4 spaces mixed, braces mostly own line.

## Incomplete / inconsistent
No lighting; alpha blending unsorted (discard <0.01), SA material alpha unread (water opaque); SA vertex colors white, material diffuse ignored. Only idle motions wired; SADX 30 / Shadow 60 fps and Shadow Euler order H. MatFX env maps/UV transforms and weapon hands unimplemented; `.UVA` read (Uva) but not applied. Level bindings per set (shared models share first texlist order). SADX welds not imported (joint gaps). TXD filter nearest vs DFF linear unresolved. Shadow levels: collision = COLI `.BSP` triangles with the port's own move rule (`moveCapsules`: sub-steps + push-out, two sided; not the game's sweep); no fog, lightmaps; objects placed without behaviour; `.RG1` kind letters (O, OS, OW, A, AF, K, G, D) unknown; all sections loaded at once. `initGlad` unused (no debug callback registered). DebugUI tabs Camera, Physics, Collision, Markers, Game; Tab (playing) opens the menu and frees the cursor; no imgui.ini. `getIdByName` checks only in Debug. `PoolMap::add` allows duplicate names (nameToId keeps first); `addUnique` throws instead. ONE owns GPU data. Shadow resources counted per archive only.
