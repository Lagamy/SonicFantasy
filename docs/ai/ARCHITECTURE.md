## State (2026-10-03 snapshot + later)
Importer stage + gameplay start: window, free-fly/follow camera, OpenGL renderer, Sonic (SADX GC) and Shadow (STH2005 GC) models/textures/motions straight from discs, levels (SADX Emerald Coast land table; Shadow stg0000/stg0100 RW worlds) with culling, collision, Lua gameplay. No lighting.

## Build
CMake ≥3.28, C++23, Ninja Debug in `build/`, one target `SonicFantasy`, Linux only (vendored static GLFW, GL, dl, pthread, m). New .cpp → `add_executable` by hand. Include dirs = `src` + every header folder (bare includes `"Camera.h"`); new folder → `target_include_directories`. Runs with cwd `build/`; `CopyShaders`/`CopyScripts` copy `Shaders/`, `Scripts/` → `build/Assets/…`. Discs: `build/Disks/Shadow2005.iso`, `SADX.iso` (`Constants.h`). Lua 5.4.7 vendored (`third-party/lua`, static lib `lua`, compiled as C++ so errors = exceptions, `LUA_USE_POSIX`). `ENGINE_DEBUG` (Debug) gates Pool/PoolMap checks. `.gitignore`: build/, dot folders, sadreamcasttools/.

## Runtime flow
createWindow (GLFW, GL 4.5 core debug) → `renderer.init` (GLAD, sRGB, depth, CCW backface cull, Default shader) → cameras[0] = player camera → `Scripting::init`, `Scripts/main.lua` → shaders, open discs (`Globals::Discs`, stay open), level (Shadow `Stg0100Level`; SADX block commented), characters (Entity + `setSAGPUInstance`/`setONEGPUInstance` from keys, idle motions; nothing imported earlier: instances find-or-load and hold a user) → loop: deltaTime, poll, `processInputs`, `gameplaySystem.update`, `Entity::update` (motions, animation intent), `gameEvents.drain()`, `renderer.run(cameras[0])` (camera UBO binding 0, levels then entities), `debugUI.draw`, swap → destroy.

## Conventions
`struct`, public members, `this->`; params end `_`, references prefixed `r` (`rCamera_`); PascalCase types/namespaces, camelCase functions/vars; origin by namespace not prefix; `#pragma once`; small utils header-only inline; explicit `init/create/destroy` (no RAII); GL 4.5 DSA (except `Texture::create` bind-to-edit); errors `throw std::runtime_error(std::format(...))`; one `/* */` block per non-obvious logical block with evidence label; tabs/4 spaces mixed, braces mostly own line.

## Incomplete / inconsistent
No lighting; alpha blending unsorted (discard <0.01), SA material alpha unread (water opaque); SA vertex colors white, material diffuse ignored. Only idle motions wired; SADX 30 / Shadow 60 fps and Shadow Euler order H. MatFX env maps/UV transforms, `.UVA`, weapon hands unimplemented. Level bindings per set (shared models share first texlist order). SADX welds not imported (joint gaps). TXD filter nearest vs DFF linear unresolved. Shadow levels: collision = COLI `.BSP` triangles with the port's own move rule (`moveCapsules`: sub-steps + push-out, two sided; not the game's sweep); no fog, lightmaps; objects placed without behaviour; `.RG1` kind letters (O, OS, OW, A, AF, K, G, D) unknown; all sections loaded at once. `initGlad` unused (no debug callback registered). DebugUI tabs Camera, Physics, Collision, Markers, Game; Tab frees cursor, click recaptures; no imgui.ini. `getIdByName` checks only in Debug. ONE owns GPU data. Shadow resources counted per archive only.
