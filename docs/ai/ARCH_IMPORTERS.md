# Architecture: importers (compact)
Part of the ARCHITECTURE twin set (index: `docs/ai/ARCHITECTURE.md`). Human source: `docs/ARCHITECTURE.md` (= ARCH; grep it for detail). Tags: E external, O observed (user), H hypothesis.

## Importers (bytes in, throw runtime_error outside support, evidence in comments, no asset names inside: names come from keys)
- GCDisc (FST, `readFile`); Rel (relocate: pointers = file offsets; SaComp first); SaComp (LZ77 of 20 SADX rels, E X-Hax).
- SALandTable (COL pieces, flags, sphere, texlist; animated parts unread). SASet (`readSAPlacements`: count + header to 0x20, 32 B records u16 type (low 12 bits type, top 4 flags unknown), s16 rot[3] BAMS, f32 pos[3], f32 scale[3] = per-object params).
- SAMdl (`importSAModel`, Ninja Basic, vertex per corner, UV/255, `texture id & 0xFFFF`, bit 0x800000 double-sided H, NPoly as strip O; normals/colors/material colors unread). SAMotion (NJS_MOTION linear only). Gvm (flags 0xF, CMPR + RGB5A3, mip 0).
- Txd (GC TXD: C4, C8 (+565/5A3 palette), RGB565, RGB5A3, CMPR; one mip; file's filter/addressing). GXTexture/GXColor decoders shared. RwMaterial (color + base texture name).
- World (`.RG1` GC native sectors: BinMesh materials, GX arrays pos/color/UV0(/UV1 ignored), strip display lists 8/16-bit indices; validated on 3092 sectors). CollisionWorld (`readCollisionWorld`: COLI `.BSP` plain sectors → CollisionMesh, raw u32 attribute/triangle, winding unknown; plane tree flattened, 0x11D collision tree unread → game's triangle visit order unavailable; loaded by `addONECollision`, all `*COLI*` `.BSP` of the sections, yawed by RenderWareYawDegrees). Dff (frames + HAnim id, non-native geometry, materials (prelit × material color; all <32 ignored), atomics, Skin; skipped BinMesh, MatFX; material UV-anim plugin 0x135 name kept as `RenderWareSubmesh::uvAnimName`, tolerant: other shapes leave it empty). Uva (`readUvaDictionary`: chunk 0x2B dict, 0x1B anim = u32 0x100, 0x1C1, nkeys, flags, f32 duration, 64 B (u32 0, name[32], 28 zeros), keys 32 B {u32 unused, time, theta, sx, sy, skew, ou, ov}, u32; 27 files of CommonEffect.one fit; key order = RpUVAnim from memory H; not applied to drawing yet).
- ONE / Prs ("One Ver 0.60", PRS; "One Ver 0.50" = common/CommonEffect.one: same but name field 32 B, so size/offset/flag at +32/+36/+40). CCL (`readCCL`, E main.dol loader: 0x20 header, 16 B records {type, ptr, flags, id}, relocation stream; Sphere 0 → form 0, Box/Plane → 3, Capsule → 6, Cylinder → 11; f4 radius, f3 half length along z H; angles radians H; file space, no yaw). Placement (`readPlacements`, LE `sky2`: 12 B header, 44 B records pos, rot deg, 2 flag words, type id, sub type, param size + params; registry 0x8052b080). RingLine (type 16, 20 B params: shape, count, a, b; shape 0 all at pos, 1 line ring i at (0,0,−a/count·i); 2/3 throw). Bon (id, name, parent, rest TRS). Model (`importModel`: parts[0] main (no BON = static); later BON part replaces same-name bone; BON-less part attaches to `ModelPart::bone`, H). Mtp/Mtn (`readMtp`, `readMtpMotion`, `readMtnMotion`; half-float keys frame/inTan/tan/value; SHADOW.MTP 158 motions fit; marker bit O).
