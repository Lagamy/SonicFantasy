## Collision / physics
- Shape forms: 0 sphere, 1/2 SADX cylinders (y), 3 box/plane, 6 capsule (Shadow along z; SADX drawn along y), 7 box-like, 11 Shadow cylinder (z, own form). Entity contacts reduce to capsules (0, 6, 11, 1/2 inscribed H) or boxes (3,4,5,7).
- **Behaviours (BA)**, our own convention: tag = category (`baTags` PoolMap); behaviour = `tags`, `availableCollisions` (tag ids it's stopped by), `availableInteractions` (tag → list of fn(parent, contact); `interactions = {[tag] = fn or {fn,...}}` in Lua). No match either side → skipped. Built-ins: tags Solid, Pickup, Hazard, Death, Body; behaviours same + Body (collides Solid), None, Passable, Object. Remaps `ShadowLevel/SADXLevel/SADXShape/ShadowShape` in External/Collision/Remaps.json (fallback + hex-string raw → behaviour name; `BABehaviors::loadRemaps` at startup, throws if wrong; members `remapX`), applied at load (`BABehaviors::resolve`, `behaviorByValue`/`fallbackBehavior`, shape `behavior`). Shadow O: 0x2, 0x202, 0x20001, 0x8, 0x28001 Solid, 0x10 Passable, 0x20 Death, else None. SADX O: all Solid except 0x00200001 Passable. Object shapes = Object; hand-made character shapes = Body. Interactions once per tick after move; parent = owner (`Collision::entityId`, none for level).
- `updateEntityContacts`: physics entity's capsule/sphere pushed out of other entities' shapes it collides with; interactions last; only shapes with a rule start a test.
- **PhysicsBody** (script-visible): velocity, `grounded`, `groundNormal`, `groundSurface`, `touchingWall`, `wallNormal`, `groundGap` (ray down, `CollisionSystem::groundGap`), `snapBlockedByWall` (H, `sf.setGroundSnapMode(e,{..,blockedByWall})`, only Shadow: ray snap move stopped by wall/ceiling before floor → not grounded; trial steps with `pushOut`, undone), `moveByMeanVelocity` (Shadow's mean-velocity move; off by default; grounded body: move's part into the floor made straight down at the same depth, `PhysicsSystem::update`, H 2026-10-07 not run), `sweepMove` (the script moves the body: gravity still added to velocity, but no engine move/collision move; `sf.setSweepMove`, `sf.sweepMove(e,x,y,z[,{radius,slides,minDot,upX,upY,upZ}])` = game sphere sweep `CollisionSystem::sweepMove` (FUN_800986f0/800221a8; returns table x,y,z,remaining*,hits,grounded,groundNormal*,normal*; sets body grounded/groundNormal/groundSurface), `sf.rayHit(e,ox,oy,oz,dx,dy,dz,len)` = FUN_800979e8 from an offset of the first shape's center → distance,nx,ny,nz; `sf.setGrounded(e,on)` = the script's final ground flag; H: file-order visit, in-place clip across triangles, slide = stop 0.02 off + drop normal part). `moveCapsules` + its ray probe/snap stay for other bodies.
- Sonic: table `_Main.rel` 0x354E10 (H Sonic's; not loaded); body sphere size 4 at 5.4 minus 5.3 feet offset (O; now the Changed file `External/Prefabs/SADX/Sonic/Changed/prefab.json`, radius 5.4; Shadow's `.../STH2005/Shadow/Changed/prefab.json`, radius 5.0). Shadow: body Capsule r5.5 length 0 (O, RAM dump; storage unknown, docs/UNKNOWNS.md).

## Gameplay
- **GameplaySystem**: `entityBehaviorTypes` (PoolMap name → `pBehave(entityId)` or Lua ref), `entityBehaviors` (Pool of {entityId, behaviorIds} stacks; `giveEntityBehavior`). Fixed tick: `tickRate` 60 (H), accumulator, ≤`maxTicksPerFrame`, excess dropped. Tick = destroyedCleanUp → keep previous positions → `SpatialIndex::updateActive` (active = within farPlane of the main camera by sphere, or `behaviorNotCulled` (player)) → behaviours (copies, skip inactive) → `PhysicsSystem::update` → `CollisionSystem::update`. Render: `extrapolate` (default; by velocity or last change, may overshoot ≤1 tick) or interpolate (a tick behind); Game tab switch.
- **Presentation**: behaviours never call renderer. `changeAnimation(id, key[, loop])` writes `animationIntent` (applied in `Entity::update` once/frame). One-shots = `postGameEvent` → `gameEvents.drain()` per frame (drops gone entities, logs if `logEvents`, handlers by name; none yet). Posted: RingCollected, DashPanelLaunch, SpringLaunch, EnemyDefeated, PlayerHurt.
- **Dash ribbon** (`Graphics/DashTrail.*`, 2026-10-07, not run): `sf.setDashTrail(e, on)` (Shadow script: on at jump dash start, off at its end / on ground) attaches/detaches a trail; `GameplaySystem::tick` end → `dashTrail.tick()` (push `Entity::position` per tick into 60 samples; detached: master alpha 255 −8/tick, removed at 0; alphas newest 0, 9 oldest ramp +32, rest master); `Renderer::run` → `dashTrail.draw()` after entities (11 ring points ×36°, triangles between samples, colour 0x7f4000 × sample alpha, Default shader, blend src alpha/one, no cull, no depth write). Original = `Eff::Belt`, STH2005_AIR_ANIM. Guards (port's own): zero direction keeps previous, vertical direction any perpendicular. sRGB colour handling unchecked.
- **Effect balls** (`Graphics/EffectBalls.*`, 2026-10-07, not run): `sf.setEffectBall(e, "jumpA"|"dashB"|"fallB", on)` (player.lua: jumpA while motion==jump, dashB while dash, fallB in fall after a dash); `GameplaySystem::tick` end → `effectBalls.tick(dt)` (age, drop dead entities); `Renderer::run` → `effectBalls.draw()` after dashTrail: per ball an additive draw (SRC_ALPHA, ONE, no depth write, no cull) of EFFCHRBALLA/B.DFF + COMMONEFFECT.TXD (common/CommonEffect.one via `Loading::addONEInstance`, keys in ResourceKeys.h; lazy on first on) with STH2005 shader uniforms `uvOffset` (vert loc 3: UVA offset at age, looping, offset only) and `effectTint` (frag loc 4: (255,128,0), alpha 0→255 over 8/60 s), reset after each ball. Placement: `ONEInstance::frameMatrix("sh_root")` × entity transform × 90° RW yaw; fallB × T(0,-5,0) × Rx(-90°) (order/sign hyp, constants in EffectBalls.cpp).
- **Scripting**: all game rules in Lua over one shared C++ physics/collision (decided with user). Hooks: `sf.prefabBehavior(prefabName, fn)` (fn(entity, placement) per entity spawnPrefab makes from that prefab, name like "SADX/SPRING"; `Scripting::setupPrefab`), global `attachPlayer(entity)`. `sf`: entities, tags, `sf.collisionBehavior(name, {tags, collidesWith, interactions})`, `sf.behavior(name, fn [, fields])` (fields {name={type number|bool|string|vec3|entity|prefab, default, external}} = `EntityBehavior::fields`; `Scripting::callBehavior(fn, entity, behaviorId)` writes them into `sf.state` before the first call: `Entity::externals[behaviour][field]` or default; Inspector Behaviour tab edits `external` ones, ENTITY/PREFAB drag-drop for refs; saved in level `externals`; per entity only; 2026-10-08 not run), `sf.give`, `sf.spawn(prefabName,x,y,z)`, bodies, events, input, rings, `sf.followCamera`, setup `sf.loadLevel(name)` ("EmeraldCoast", "Stg0100"; recipes = C++ tables in ScriptAPI.cpp, no raw keys in Lua), `sf.spawnPlayer("sonic"|"shadow",x,y,z)` (model, idle, Changed-file body shape, physics 1; script then calls `attachPlayer`), `sf.setCamera(x,y,z)` `sf.unloadLevel(level)` (queued; `Scripting::processPendingUnloads` at start of next tick), `sf.levelExists(level)` (run from `Scripts/game.lua`; L key = `LevelSwitch` behaviour cycles `ORDER`, moves players to the new starts, `recordPlayerStarts()`; 2026-10-07 not run), `sf.state(entity)` (Lua table, `scriptStateRef`). Handles are packed PoolId ints, `sf.none` = −1. Libs: base, table, string, math, utf8, coroutine (no io/os/package/debug/dofile/loadfile). Lua doubles (bit-exact not a goal). Not scripted: camera control beyond start/follow, reload,  contact points/normals.
