To make the editor complete (and mods able to define their own triggers and collisions) it must be able to create them:

  - **New BoundArea entry.** Add a bound area to an entity, choosing its shape from the existing ones (box, capsule, sphere), and select the tags it carries.
  - **Rules of a bound area, edited in the editor (user's structure, 2026-10-09).** The owner is the bound area's collision behaviour (`BABehavior`), not the tag. Two lists:
    - **Behaviours list**: `{ OnTouchBehavior {TagId, TagId, TagId}, OnTouchBehavior2 {TagId, TagId, TagId} }`: each entry is an onTouch behaviour (function) with the tags whose overlap triggers it.
    - **Collision list**: `{TagId, TagId, TagId}`: the tags this bound area collides with.
    - The bound area's own tags (what it is) are chosen separately, when the entry is added (above).
