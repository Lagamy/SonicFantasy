name: shadow-replay-compare
description: Compare the Lua Shadow port against the original game by replaying a recorded pad input (tools/shadowLiveLog.py, makeReplay.py, replay.lua, compareReplay.py). Use when the user records a new live CSV, pastes a comparison table, or wants a port behaviour matched to the original.
---

Read first: `docs/ai/REPLAY.md` (method, limits, recordings, latest status) and, from the `docs/ai/STH2005_*.md` twins, only the topic file the difference is about (index at the top of `docs/ai/STH2005_PLAYER.md`: ground, collision, air/animation). They are compact twins of `docs/REPLAY_COMPARISON.md` and `docs/STH2005_PLAYER_REFERENCE.md`; open those only for a specific section (grep the heading, read with offset/limit: the reference is ~130 KB).

Summary: user records the original with `tools/shadowLiveLog.py --pad 8056ED4C tools/<name>.csv` (the logger always adds the camera columns `cam_eye_x/y/z`, `cam_target_x/y/z`) -> `python3 tools/makeReplay.py tools/<name>.csv Scripts/shadow/replays/<name>.lua` (phi from the camera columns, or from the world stick vector on older CSVs; `--check-camera --ai` instead of the output path compares the two) -> register in `Scripts/shadow/main.lua` and `ORDER` in `replay.lua` -> user builds, runs the port with stdout redirected, presses R -> `python3 tools/compareReplay.py tools/<name>.csv tools/port_run.txt <name> --ai` (compact; drop `--ai` only for the human tables). To look at frames, `python3 tools/digestRun.py tools/<name>.csv --from T --to T` and `python3 tools/digestRun.py tools/port_run.txt <name> --from T --to T` (same columns, port axes); never read the raw CSV (4 KB a row of memory dumps) or REPLAY lines directly.

Rules (CLAUDE.md): never run the app or build, and never run shadowLiveLog.py (it overwrites its CSV); run only the python analysis tools on existing files. Label claims observed / external / hypothesis; port observed behaviour quirks included; write findings to `docs/STH2005_PLAYER_REFERENCE.md` section 20+ and run results to `docs/REPLAY_COMPARISON.md`, and update their twins in `docs/ai/` in the same task; run `python3 tools/notifyDone.py` last. Treat 1 to 2 frame alignment error and the -11.34 rest vy as known, not bugs. Rules fitted to a recording need a different recording to validate.

All tool arguments and flags: skill `project-tools` (compact) and `docs/TOOLS.md` (human); update both when a tool changes.
